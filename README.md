# 🔐 Enigma do Cellbit - Encriptador de Senhas Educativo

Um site interativo para aprender sobre criptografia de forma prática. Digite uma senha, escolha um método de criptografia e veja passo a passo como a senha é transformada.

## ✨ Funcionalidades

- Criptografia por deslocamento (Caesar Cipher)
- Método de reversão
- Codificação em Base64
- Criptografia XOR com chave
- Explicação do passo a passo
- Instruções de descriptografia
- Botão para copiar o resultado
- Layout responsivo

## ▶️ Como abrir

1. Abra o arquivo `index.html` no navegador.
2. Ou rode um servidor local, por exemplo:

```bash
python3 -m http.server 8000
```

Depois visite:

```text
http://localhost:8000
```

## 🧠 O que o projeto ensina

- Como funciona a transformação de uma senha em texto codificado
- Como reverter o processo para voltar ao original
- Conceitos básicos de criptografia e codificação
- Diferença entre criptografia e codificação
